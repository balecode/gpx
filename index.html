    Akses Lokasi di Smartphone

    Mengapa GPS Diblokir?

    Browser smartphone (Chrome & Safari) membatasi sensor GPS langsung hanya untuk HTTPS atau localhost. Karena halaman ini dibuka via IP jaringan lokal (http://192.168.x.x), browser HP menolak akses GPS dengan pesan "Only secure origins are allowed".

    Solusi & Alternatif yang Dapat Anda Gunakan:

    Rekomendasi Cepat 1. Gunakan Perkiraan Lokasi Jaringan (IP)

    Perkirakan posisi Anda berdasarkan lokasi ISP / jaringan internet secara instan tanpa perlu setelan teknis di HP.

    Android Chrome 2. Bypass GPS Akurat di Chrome Android
    1. Buka tab baru di browser Chrome HP Anda:
      chrome://flags/#unsafely-treat-insecure-origin-as-secure
    2. Ketik / paste alamat IP web ini di kolom isian:
    3. Ubah pilihan dari Default menjadi Enabled.
    4. Tekan tombol biru Relaunch di pojok bawah Chrome. Sensor GPS HP Anda kini aktif 100%!
    HTTPS Tunnel 3. Jalankan Local HTTPS Tunnel di Laptop

    Jalankan perintah ini di PowerShell laptop/PC Anda untuk mendapatkan tautan HTTPS instan:

    npx localtunnel --port 5500

    Lalu buka URL https://... yang dihasilkan pada browser HP Anda.
